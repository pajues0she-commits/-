# 📋 업무 플래너 (Work Planner)

심플하게 쓰는 업무 관리 PC앱입니다. 별도 회원가입·인터넷 연결 없이, 모든 데이터는 내 PC에 자동 저장됩니다.

## 주요 기능

| 메뉴 | 기능 |
|------|------|
| 📝 할 일 목록 | 해야 할 일을 모두 등록하고 한눈에 보기 |
| 📋 세부 계획 | 업무마다 **메모 + 세부 항목 체크리스트** 작성, 카드에 진행률(📋 2/5) 표시. **세부 항목에 기한을 넣으면 그 날짜부터 오늘 계획에 표시** |
| 🔴🟠🟡🟢 자동 분류 | **중요한 일 / 덜 중요한 일 × 급한 일 / 천천히 해도 되는 일** 4가지로 구분 (아이젠하워 매트릭스) |
| 📅 월간 업무 | 달력에서 한 달 업무를 한눈에 조회 (**루틴 업무는 점선으로 표시**) |
| 🗓️ 주간 업무 | 이번 주 요일별 업무 조회 (루틴 포함) |
| 📆 일간 업무 | 하루 단위 업무 조회 (완료/미완료/루틴 구분) |
| ⏰ 오늘 시간 계획 | 오늘 업무를 06시~23시 시간대별로 계획 (자동 저장). **할 일을 시간대로 드래그 앤 드롭**해서 배치하고, **체크박스로 완료 처리하면 완료 이력에 자동 반영** |
| 🔁 루틴 업무 | **매일/매주/매월/매년 반복 업무를 등록하면 자동으로 할 일에 추가되고, 지정 시간에 알림** (데스크톱 알림 + 앱 내 팝업 + 알림음). **매년 루틴은 지정한 날짜가 매년 마감으로 미리 등록** |
| ✅ 완료 이력 | 완료 시 **조치 내용을 기록**하고, 월별 이력 조회·검색 |

## 실행 방법

### 개발 실행 (Node.js 필요)

```bash
cd work-planner
npm install
npm start
```

### Windows용 실행 파일(.exe) 만들기

```bash
npm run dist
```

`dist/` 폴더에 설치 없이 바로 실행되는 포터블 exe가 생성됩니다.

### Electron 없이 바로 써보기

`index.html` 파일을 크롬/엣지 브라우저로 열어도 동일하게 동작합니다.
(데이터는 브라우저 localStorage에 저장됩니다.)

## 사용법 (심플!)

1. **할 일 목록**에서 할 일 입력 → 중요도/긴급도 선택 → 마감일 지정 → `+ 추가`
2. 목록은 자동으로 4가지 우선순위 그룹으로 정렬됩니다. 🔴 중요+급함 부터 처리하세요.
3. **월간/주간/일간** 메뉴에서 마감일 기준으로 업무를 조회합니다.
4. **오늘 시간 계획**에서 시간대 칸에 직접 입력하거나, 오른쪽 할 일을 **원하는 시간대로 드래그**(또는 시간대 선택 후 클릭)해 넣습니다.
   - 끝낸 계획은 **왼쪽 체크박스**로 완료 처리 → 연결된 할 일이 완료되고 **완료 이력**에 기록됩니다
5. 일을 끝내면 `✓ 완료` 버튼 → **조치 내용**을 기록 → **완료 이력**에 저장됩니다.
6. **루틴 업무**에서 반복 주기(매일/매주 요일/매월 날짜/매년 월·일)와 알림 시간을 정해 등록하면:
   - 주기가 되는 날 할 일 목록에 자동 추가됩니다 (🔁 표시)
   - **매년 루틴**은 지정한 날짜가 다가오는 해의 마감(📌 연간)으로 미리 등록됩니다
   - 지정한 시간에 데스크톱 알림 + 앱 내 팝업 + 알림음이 울립니다 (하루 1회)
   - 🔕 버튼으로 알림을 끄거나 다시 켤 수 있습니다

> 알림은 앱이 실행 중일 때 울립니다. 업무 시간 동안 앱을 켜두거나 최소화해 두세요.

## 데이터 저장 위치

- Electron 앱: 사용자 프로필의 앱 데이터 폴더 (localStorage)
- 브라우저: 해당 브라우저의 localStorage

앱을 껐다 켜도 데이터가 유지됩니다.
