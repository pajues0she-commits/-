# 🐶 멍멍 건강수첩 — 견종별 강아지 건강관리 앱

체중·체고·몸통 둘레 등 반려견의 핵심 수치를 기록하고, **견종별 표준값**을 기준으로
**비만도**와 성장·건강 추이를 트렌드 차트로 확인할 수 있는 웹 앱입니다.

외부 라이브러리·서버 없이 동작하는 순수 HTML/CSS/JavaScript 앱으로, 모든 데이터는
브라우저의 `localStorage`에 저장됩니다.

## 주요 기능

- **여러 마리 프로필 관리** — 이름·견종·성별·중성화·생년월일 등록, 나이 자동 계산
- **핵심 수치 기록** — 체중(kg), 체고(cm), 몸통 둘레(cm), 목 둘레(cm), 메모, 측정일
- **견종별 비만도 자동 평가**
  - 22종 견종의 표준 체중/체고/몸통 둘레 데이터 내장
  - 이상 체중 대비 비만도(%) 계산 → 저체중 / 정상 / 과체중 / 비만 4단계 판정
  - BCS(Body Condition Score, 9단계) 근사 추정 및 맞춤 조언
  - 시각적 비만도 게이지
- **트렌드 차트** (자체 SVG 렌더링) — 체중 · 비만도 · 체고 · 몸통 둘레 추이
  - 견종 표준 범위를 밴드로, 이상 체중을 점선으로 표시
- **견종별 주요 관리 포인트** — 슬개골·기관 허탈·디스크·비만 등 견종 특성별 건강 팁
- **기록 내역 테이블** — 변화량 표시, 개별 수정/삭제
- **데이터 백업/복원** — JSON 파일로 내보내기·가져오기
- **반응형 + 다크모드** 지원

## 사용 방법

정적 파일이라 별도 빌드가 필요 없습니다.

```bash
# 아무 정적 서버로 실행 (예)
cd dog-health
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저에서 직접 열어도 됩니다.

1. **＋ 강아지 추가**로 반려견을 등록합니다.
2. **＋ 수치 기록**으로 측정값을 입력합니다.
3. 대시보드에서 비만도·트렌드·견종별 관리 포인트를 확인합니다.

## 파일 구조

```
dog-health/
├── index.html          # 앱 진입점
├── css/styles.css      # 스타일 (라이트/다크, 반응형)
└── js/
    ├── breeds.js       # 견종 표준 데이터 (체중/체고/둘레/관리 팁)
    ├── health.js       # 비만도·BCS·나이 등 건강 지표 계산
    ├── store.js        # localStorage 데이터 저장소
    ├── chart.js        # 의존성 없는 SVG 라인 차트
    └── app.js          # 화면 렌더링 & 이벤트 처리
```

## 데이터 기준에 대한 참고

견종별 표준 체중·체고·몸통 둘레와 비만도 판정 기준은 일반적으로 통용되는
참고 범위를 바탕으로 합니다. 개체마다 골격·근육량 차이가 있으므로,
정확한 건강 상태 평가와 진단은 **반드시 수의사와 상담**하시기 바랍니다.
