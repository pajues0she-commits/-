# 🐶 멍멍 건강수첩 — 견종별 강아지 건강관리 앱

체중·체고·몸통 둘레 등 반려견의 핵심 수치를 기록하고, **견종별 표준값**을 기준으로
**비만도**와 성장·건강 추이를 트렌드로 확인하는 **모바일 앱(PWA)** 입니다.

하단 탭 내비게이션·플로팅 버튼·바텀시트 등 네이티브 앱 형태의 UI로 만들어졌으며,
홈 화면에 **설치**하면 전체화면 앱처럼 실행되고 **오프라인**에서도 동작합니다.
외부 라이브러리·서버 없이 순수 HTML/CSS/JavaScript로 구현되어 모든 데이터는
브라우저의 `localStorage`에 저장됩니다.

## 주요 기능

- **모바일 앱 UI** — 홈 / 트렌드 / 기록 / 더보기 4개 탭, FAB(빠른 기록), 바텀시트 입력
- **여러 마리 프로필 관리** — 상단 강아지 칩으로 전환, 이름·견종·성별·중성화·생년월일, 나이 자동 계산
- **핵심 수치 기록** — 체중(kg), 체고(cm), 몸통 둘레(cm), 목 둘레(cm), 메모, 측정일
- **견종별 비만도 자동 평가**
  - 22종 견종의 표준 체중/체고/몸통 둘레 데이터 내장
  - 이상 체중 대비 비만도(%) 계산 → 저체중 / 정상 / 과체중 / 비만 판정
  - BCS(Body Condition Score, 9단계) 근사 추정 및 맞춤 조언, 시각적 게이지
- **트렌드 차트** (자체 SVG 렌더링) — 체중 · 비만도 · 체고 · 몸통 둘레 추이
  - 견종 표준 범위를 밴드로, 이상 체중을 점선으로 표시
- **견종별 주요 관리 포인트** — 슬개골·기관 허탈·디스크·비만 등 견종 특성별 건강 팁
- **데이터 백업/복원** — JSON 파일로 내보내기·가져오기
- **PWA** — 홈 화면 설치, 오프라인 지원(서비스워커), 다크모드, 안전영역(노치) 대응

## 설치 & 실행

정적 파일이라 별도 빌드가 필요 없습니다.

```bash
cd dog-health
python3 -m http.server 8000
# 휴대폰/브라우저에서 http://<PC-IP>:8000 접속
```

- **iPhone (Safari)**: 공유 → "홈 화면에 추가"
- **Android (Chrome)**: 메뉴 → "앱 설치" / "홈 화면에 추가"

설치하면 주소창 없는 전체화면 앱으로 실행됩니다.

### 사용법
1. 첫 실행 시 **＋ 강아지 추가하기**로 반려견을 등록합니다.
2. 우측 하단 **＋** 버튼으로 측정 수치를 기록합니다.
3. **홈**에서 비만도·관리 포인트를, **트렌드**에서 추이를 확인합니다.

## 파일 구조

```
dog-health/
├── index.html              # 모바일 앱 셸 (앱바 + 탭바 + FAB + 시트)
├── manifest.webmanifest    # PWA 매니페스트
├── sw.js                   # 서비스워커 (오프라인 캐싱)
├── css/styles.css          # 모바일 우선 스타일 (라이트/다크)
├── icons/                  # 앱 아이콘 (SVG + PNG 192/512 + maskable)
└── js/
    ├── breeds.js           # 견종 표준 데이터 (체중/체고/둘레/관리 팁)
    ├── health.js           # 비만도·BCS·나이 등 건강 지표 계산
    ├── store.js            # localStorage 데이터 저장소
    ├── chart.js            # 의존성 없는 SVG 라인 차트
    └── app.js              # 화면 전환 & 렌더링 & 이벤트 처리
```

## 데이터 기준에 대한 참고

견종별 표준 체중·체고·몸통 둘레와 비만도 판정 기준은 일반적으로 통용되는
참고 범위를 바탕으로 합니다. 개체마다 골격·근육량 차이가 있으므로,
정확한 건강 상태 평가와 진단은 **반드시 수의사와 상담**하시기 바랍니다.
