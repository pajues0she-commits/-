# MSDS 변경 판정·누적 관리 앱

사업장에 화학물질을 도입할 때 받은 MSDS(물질안전보건자료)를 **누적 관리**하면서,
**연도별로 제조사 변경 여부와 성분·함유량 변경 여부를 자동 판정**해 주는
PC(데스크톱) 앱입니다.

GUI는 Tkinter — 별도 프레임워크 설치 없이 Windows/macOS/리눅스의 기본
Python으로 실행됩니다.

## 주요 기능

- **드래그 앤 드롭 업로드** — MSDS 파일(PDF/TXT)을 창에 끌어다 놓으면 등록
  (tkinterdnd2 설치 시. 미설치 시에는 [MSDS 파일 추가…] 버튼 사용)
- **등록 정보 입력** — 작성부서·작성자·**도입일자**를 입력하면 등록되는
  모든 파일에 함께 기록 (도입일자는 목록에서 더블클릭으로 개별 수정 가능)
- **기준연도 = 도입일자의 연도** — 입력한 도입일자(YYYY-MM-DD)의 연도가
  해당 MSDS의 기준연도로 자동 인식되어 연도별 비교의 기준이 됩니다.
  입력란 옆에 인식된 기준연도가 실시간으로 표시되며, 도입일자를 비워 두면
  MSDS 문서의 개정연도를 대신 사용합니다.
- **누적 관리** — 업로드한 MSDS는 파싱 결과와 원본 사본이 로컬 저장소
  (`~/.msds_checker`)에 보관되어, 앱을 껐다 켜도 이력이 유지됩니다
- 문서에서 자동 추출:
  - **MSDS 문서연도(참고용)** — 개정일/작성일에서 추출, 없으면 파일명의 연도
    사용. 도입일자가 없을 때 기준연도 대체값으로 쓰입니다.
  - **제조사/공급자** — 1항(화학제품과 회사에 관한 정보)의 회사명.
    `회 사 명 :`처럼 글자 사이 공백이 있는 표기, `O` 불릿, 뒤에 붙는
    사업장명·담당부서 꼬리표도 처리
  - **제품명** — `제품명` 외에 `물질명` 라벨도 인식
  - **구성성분** — 3항의 성분명·CAS 번호·함유량 (CAS 체크섬 검증으로 오인식 방지).
    PDF 표가 열 단위로 흩어져 추출되는 문서(예: OCI 양식)는 CAS와 함유량을
    줄 간 거리 기준으로 재조합해 복원
- **연도별 판정 매트릭스** — 연도를 열로, 정보등록 판정·제조사·각 성분을 행으로
  하여 변경된 칸을 ▲와 빨간색으로 표시:
  - 제조사: (주)·주식회사·Co., Ltd. 등 법인 표기 차이는 동일 회사로 간주
  - 성분: 추가·삭제·함유량 변경을 CAS 번호 기준으로 감지
- **정보등록 판정** — 제조사 또는 구성성분·함량이 변경된 경우에만
  `○ 등록대상`, **변경이 없으면 `✕ 비대상`**(정보등록 대상 아님)으로 판정.
  첫 등록 연도는 `최초등록 · ○ 대상`, 추출 실패 시 `? 확인필요`
- **엑셀 내보내기(.xlsx)** — 시트1 `누적 이력`(도입일자·제품·제조사·성분 상세·
  작성부서·작성자), 시트2 `연도별 판정`(변경 칸 강조 서식 포함)
- **보고서 저장** — 텍스트 보고서(.txt) 또는 CSV 요약(.csv)

## 설치 및 실행

Python 3.10 이상이 필요합니다. (Windows용 Python에는 Tkinter가 기본 포함)

```bash
cd msds-checker
pip install -r requirements.txt   # pypdf(PDF), openpyxl(엑셀), tkinterdnd2(드래그)
python main.py
```

### 사용 방법

1. 상단 **등록 정보**에 작성부서·작성자·도입일자를 입력합니다.
   도입일자의 연도가 **기준연도**로 인식되어 입력란 옆에 표시됩니다.
2. MSDS 파일을 **창으로 드래그**하거나 **[MSDS 파일 추가…]** 로 첨부합니다.
   → 입력해 둔 도입일자·부서·작성자와 함께 누적 이력에 저장되고,
   기준연도는 도입일자의 연도로 설정됩니다.
3. 목록에서 도입일자·기준연도·제조사·성분 수가 제대로 인식됐는지 확인합니다.
   도입일자(기준연도)가 틀리면 해당 칸을 **더블클릭**해 수정하세요.
4. **[판정 실행]** — 연도×항목 매트릭스와 상세 보고서가 표시됩니다.
5. **[엑셀 내보내기…]** — 누적 관리 대장과 판정 결과를 .xlsx로 추출합니다.

`samples/` 폴더에 동작을 확인할 수 있는 예시 MSDS 3개(2022/2023/2024년)가
들어 있습니다.

### 누적 데이터 저장 위치

- 기본: `~/.msds_checker/history.json` (+ 파일 사본은 `files/` 하위)
- 환경변수 `MSDS_DATA_DIR`로 변경할 수 있습니다.

### 실행 파일(.exe)로 만들기 (선택)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name MSDS변경판정 main.py
# dist/MSDS변경판정.exe 생성
```

## 테스트

```bash
python -m unittest discover tests
```

## 제한 사항

- **스캔 이미지로만 된 PDF**는 텍스트를 추출할 수 없어 판정 불가로 표시됩니다
  (OCR 미지원). 텍스트 레이어가 있는 PDF를 사용하세요.
- MSDS 양식이 표준(고용노동부 고시 16개 항목)과 크게 다르면 추출이 실패할 수
  있으며, 이 경우 목록의 비고란에 경고가 표시됩니다. 판정은 추출된 정보
  기준이므로 최종 확인은 원문 대조를 권장합니다.

## 프로젝트 구조

```
msds-checker/
├── main.py                  # 실행 진입점
├── msds_checker/
│   ├── parser.py            # PDF/TXT → 연도·제조사·성분 추출
│   ├── comparator.py        # 연도별 비교 판정 + 매트릭스/보고서 생성
│   ├── storage.py           # 누적 이력 저장소 (JSON + 파일 사본)
│   ├── exporter.py          # 엑셀(.xlsx) 내보내기
│   └── gui.py               # Tkinter GUI (드래그 앤 드롭 지원)
├── samples/                 # 예시 MSDS (2022~2024)
└── tests/                   # 단위 테스트
```
