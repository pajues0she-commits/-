# MSDS 연도별 변경 판정 앱

MSDS(물질안전보건자료) 파일을 여러 개 첨부하면 **연도별로 제조사 변경 여부와
구성성분 변경 여부를 자동 판정**해 주는 PC(데스크톱) 앱입니다.

![구조] GUI(Tkinter) — 별도 프레임워크 설치 없이 Windows/macOS/리눅스의 기본
Python으로 실행됩니다.

## 주요 기능

- **PDF / TXT 형식 MSDS 첨부** (여러 파일 동시 선택 가능)
- 문서에서 자동 추출:
  - **연도** — 16항 등의 개정일/작성일에서 추출, 없으면 파일명의 연도 사용
    (둘 다 없으면 목록에서 더블클릭해 직접 입력)
  - **제조사/공급자** — 1항(화학제품과 회사에 관한 정보)의 회사명
  - **구성성분** — 3항의 성분명·CAS 번호·함유량 (CAS 체크섬 검증으로 오인식 방지)
- **연도별 판정** — 인접 연도끼리 비교해 구간별로 표시:
  - 제조사: `변경` / `변경없음` / `판정불가` — (주)·주식회사·Co., Ltd. 등
    법인 표기 차이는 동일 회사로 간주
  - 성분: 추가·삭제·함유량 변경을 각각 상세 표시 (CAS 번호 기준 매칭)
- **보고서 저장** — 텍스트 보고서(.txt) 또는 엑셀용 요약(.csv)

## 설치 및 실행

Python 3.10 이상이 필요합니다. (Windows용 Python에는 Tkinter가 기본 포함)

```bash
cd msds-checker
pip install -r requirements.txt   # PDF 읽기용 pypdf
python main.py
```

### 사용 방법

1. **[MSDS 파일 추가…]** 로 연도별 MSDS 파일들을 첨부합니다.
2. 목록에서 연도·제조사·성분 수가 제대로 인식됐는지 확인합니다.
   연도가 틀리면 해당 행을 **더블클릭**해 수정하세요.
3. **[판정 실행]** 을 누르면 연도 구간별 판정 결과와 상세 보고서가 표시됩니다.
4. **[보고서 저장…]** 으로 .txt 또는 .csv로 내보낼 수 있습니다.

`samples/` 폴더에 동작을 확인할 수 있는 예시 MSDS 3개(2022/2023/2024년)가
들어 있습니다.

### 실행 파일(.exe)로 만들기 (선택)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name MSDS변경판정 main.py
# dist/MSDS변경판정.exe 생성
```

## 테스트

```bash
python -m unittest discover tests
```

## 제한 사항

- **스캔 이미지로만 된 PDF**는 텍스트를 추출할 수 없어 판정 불가로 표시됩니다
  (OCR 미지원). 텍스트 레이어가 있는 PDF를 사용하세요.
- MSDS 양식이 표준(고용노동부 고시 16개 항목)과 크게 다르면 추출이 실패할 수
  있으며, 이 경우 목록의 비고란에 경고가 표시됩니다. 판정은 추출된 정보
  기준이므로 최종 확인은 원문 대조를 권장합니다.
