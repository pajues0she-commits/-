# 유해화학물질 취급시설 자체점검 모바일 앱

화학물질관리법 시행규칙 **[별지 제42호서식] `유해화학물질취급시설 자체점검대장`** 을
**시설별로** 점검·저장하고, 그 결과를 **원본 양식 그대로 A4 PDF**로 만들어 **이메일 전송**하거나 내려받는 모바일 웹앱(PWA)입니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| **시설별 점검 작성** | **시설명**(정해진 10개 시설 중 선택)·점검연월일·시간·소속·점검자·**손가락 서명**과 12개 점검 항목(각 3개 선택지: 문제없음 / 자체점검 시 조치완료 / 정밀 재점검 필요)을 입력 |
| **결과 저장** | 점검 결과를 기기에 저장(오프라인) |
| **시설별 폴더 조회** | `내역` 탭이 **시설별 폴더**로 구성됩니다. 각 폴더에 점검 건수·재점검 필요 건수가 표시되고, 폴더를 열면 해당 시설의 점검 결과 목록을 조회(메일 전송·PDF 저장·삭제)할 수 있습니다 |
| **이메일로 바로 전송** | 버튼을 누르면 **설정에 저장한 수신 이메일 주소로 메일 작성창**이 바로 열립니다(공유 시트 없음). 결과 PDF(별지 제42호서식 · A4 세로)는 자동으로 내려받아지며, 메일에 첨부 후 보내면 됩니다. 수신 이메일이 없으면 처음 한 번만 입력받아 저장 |
| **PDF로 저장 (A4)** | 결과를 **A4 세로(210㎜×297㎜) 규격 PDF**로 생성. 저장 전 미리보기로 확인 후 내려받기 |
| **양식 미리보기·인쇄** | 원본 양식과 동일한 미리보기를 확인하고 A4 세로로 바로 인쇄 |
| **오프라인 · 홈 화면 설치** | 서비스 워커로 오프라인 동작, 모바일 홈 화면에 앱처럼 설치 가능 |

## 실행 방법

**가장 간단한 방법 — 단일 파일:** `app/standalone.html` 한 파일에 모든 코드·라이브러리가 들어 있어
브라우저에서 파일을 바로 열기만 하면 됩니다(서버 불필요). 휴대폰으로 공유하거나 어디서든 열어 미리 볼 수 있습니다.

> 단, 파일 첨부 이메일 공유(Web Share API)와 홈 화면 설치·오프라인 캐시는 `file://`가 아닌
> HTTPS(또는 localhost)에서만 동작하므로, 실제 배포는 아래 서버 방식을 권장합니다.

**서버로 서빙:** 임의의 웹 서버에서 `app/` 디렉터리를 서빙하세요.

```bash
cd app
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

모바일에서 사용하려면 이 `app/` 폴더를 HTTPS로 서빙되는 정적 호스팅
(GitHub Pages, Netlify, 사내 웹서버 등)에 올린 뒤 휴대폰으로 접속하고,
브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 설치됩니다.

> 서비스 워커(오프라인)·홈 화면 설치는 **HTTPS**(또는 localhost)에서만 동작합니다.
> PDF 생성·저장·인쇄는 `file://`로 열어도 정상 동작합니다.

## 사용 순서

1. `점검` 탭에서 **시설명(목록에서 선택)**·기본정보·서명·12개 항목을 입력합니다. (상단 **모두 문제없음**으로 일괄 설정 후 예외만 변경 가능)
2. **저장** 버튼으로 결과를 기기에 저장합니다.
3. **이메일로 전송**을 누르면 **설정에 저장한 수신 이메일 주소로 메일 작성창**이 열리고 A4 PDF가 내려받아집니다. 메일에 PDF를 첨부해 보내면 됩니다. (웹 보안상 첨부까지 자동은 불가 — 완전 자동 발송은 별도 메일 서버 필요)
4. **PDF로 저장 (A4)**를 누르면 **A4 세로 규격 PDF** 미리보기 후 내려받습니다. 필요 시 **양식 미리보기·인쇄**로 인쇄합니다.
5. `내역` 탭에서 **시설별 폴더**를 열어 해당 시설의 점검 결과를 확인하고, 각 내역을 다시 전송·저장·삭제할 수 있습니다.
6. `설정` 탭에서 기본 수신 이메일·기본 소속·기본 점검자를 지정하면 매번 자동 입력됩니다.

## 파일 구성

```
app/
├── index.html      화면 구조(점검 / 내역 / 설정 탭)
├── styles.css      모바일 UI + 별지 제42호서식 양식 스타일 + 인쇄 규칙
├── data.js         12개 점검 항목·선택지·양식 메타데이터(원문)
├── form.js         저장 결과 → 별지 제42호서식 레이아웃 DOM 생성기
├── app.js          상태 관리·시설별 저장/내역·서명·A4 PDF 생성·이메일/인쇄 로직
├── sw.js           오프라인 캐시 서비스 워커
├── manifest.webmanifest   PWA 설치 매니페스트
├── vendor/         jsPDF, html2canvas (오프라인 번들, 로컬 포함)
└── icons/          앱 아이콘
```

## 기술 메모

- 데이터는 브라우저 `localStorage`에 저장됩니다(서버 불필요, 오프라인 동작). 기기/브라우저별로 보관되므로 `설정 > 전체 내역 백업(JSON)`으로 백업할 수 있습니다.
- PDF는 양식 DOM을 `html2canvas`로 캡처해 `jsPDF`의 **A4 세로(210㎜×297㎜)** 페이지에 넣어 생성하므로 원본 서식과 동일한 규격이며 한글이 완전하게 표현됩니다.
- 외부 CDN 의존 없이 `vendor/`에 라이브러리를 포함하여 오프라인에서도 동작합니다.
