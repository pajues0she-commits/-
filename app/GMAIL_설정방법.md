# Gmail 자동 발송 설정 (Google 계정으로 보고서 이메일 보내기)

앱에서 **이메일로 전송** 버튼을 누르면, 내 Google 계정(Gmail)으로 점검 PDF가
수신자에게 **자동 발송**되도록 하는 설정입니다. (다운로드·공유창 없이 바로 전송)

원리: Google Apps Script로 만든 작은 “발송 서버”를 내 Google 계정에 배포하고,
그 주소를 앱에 등록합니다. 앱이 그 주소로 PDF를 보내면 스크립트가 내 Gmail로 메일을 보냅니다.

---

## 1) Apps Script 만들기

1. PC 또는 휴대폰 브라우저에서 <https://script.google.com> 접속 → **새 프로젝트**.
2. 기본 코드(`function myFunction() {}`)를 모두 지우고, 이 저장소의
   **`google-apps-script.gs`** 파일 내용을 전부 복사해 붙여넣습니다.
3. 상단 💾(저장) 클릭.

## 2) 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱** 선택.
3. 설정:
   - **실행 계정(Execute as)**: `나(me)`
   - **액세스 권한(Who has access)**: `모든 사용자(Anyone)`
4. **배포** 클릭 → 처음이면 **권한 승인** 창이 뜹니다.
   - 내 Google 계정 선택 → “Google에서 확인하지 않은 앱” 경고가 나오면
     **고급 → (프로젝트 이름)(으)로 이동 → 허용** 을 누릅니다.
     (내가 만든 내 스크립트이므로 안전합니다. Gmail 보내기 권한을 승인합니다.)
5. 배포가 완료되면 **웹 앱 URL** 이 나옵니다. 예:
   `https://script.google.com/macros/s/AKfy..../exec`
   → 이 **/exec 로 끝나는 URL** 을 복사합니다.

## 3) 앱에 등록

1. 자체점검 앱 → **설정** 탭 → “Gmail 자동 발송(Google 계정)” 항목.
2. **Gmail 발송 웹앱 URL** 칸에 방금 복사한 `/exec` 주소를 붙여넣고 **Gmail 설정 저장**.
3. **테스트 메일 보내기** 를 눌러 수신함에 도착하는지 확인하세요.
   (받는 주소는 설정의 “기본 수신 이메일”을 사용합니다.)

## 4) 사용

- 이제 점검 후 **이메일로 전송** 을 누르면, 설정의 “기본 수신 이메일” 주소로
  **내 Gmail 계정에서 PDF가 첨부된 메일이 자동 발송**됩니다.
- 받는 사람을 바꾸려면 설정의 “기본 수신 이메일”을 변경하세요.

---

## 참고 / 문제 해결

- **HTTPS 필요**: 앱은 HTTPS 주소(예: Netlify 배포본)에서 사용하세요.
- **메일이 안 와요**:
  - 웹앱 URL이 `/exec` 로 끝나는지 확인.
  - Apps Script 배포 시 액세스 권한이 **모든 사용자(Anyone)** 인지 확인.
  - 코드 수정 후에는 **배포 → 배포 관리 → 편집 → 새 버전 → 배포** 로 갱신.
  - Gmail 일일 발송 한도(개인 계정 약 500통/일)를 넘지 않았는지 확인.
- **보안**: 이 웹앱 URL을 아는 사람은 내 계정으로 메일을 보낼 수 있으므로 URL을 공개하지 마세요.
- Gmail 자동 발송을 끄려면 설정에서 URL을 지우고 저장하면 됩니다(메일 앱 공유 방식으로 동작).
