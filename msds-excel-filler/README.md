# MSDS 자동 작성 도구 — 관리요령 엑셀 · 유해화학물질 규격표지

MSDS(물질안전보건자료) PDF를 업로드하면 두 가지 산출물을 자동으로 만들어 주는
프로그램입니다. 업로드한 물질은 두 메뉴 모두에서 함께 사용됩니다.

1. **화학물질 작업공정별 관리요령** — 「화학물질 작업공정별 관리 요령」 엑셀 양식을
   자동으로 채웁니다. 결과물은 원본 양식과 동일한 서식(병합 셀·글꼴·테두리·
   GHS 그림문자 포함)의 `.xlsx` 파일로 다운로드됩니다. PDF를 여러 개 올리면
   물질별로 시트가 하나씩 생성됩니다.
2. **유해화학물질 규격표지** — 화학물질관리법 시행규칙 [별표 2]
   「유해화학물질의 표시방법」(제12조제2항 관련) 1호(보관·저장시설 또는 진열·보관
   장소 표지) 규격에 맞는 표지판 시안을 만듭니다.
   - 규격: **a=50cm**, b=(3/2)a=**75cm**, c=(1/4)a=**12.5cm**, d=(1/4)a=**12.5cm**
   - 색상: 바탕 흰색 / 테두리 검정 / "유해화학물질" 글자 빨강(테두리 높이의 65% 이상)
     / 관리책임자·비상전화 글자 검정
   - 하단 표에는 업로드한 MSDS에서 추출한 **물질명·국제연합번호(14항 운송에 필요한
     정보)·GHS 그림문자**가 자동으로 채워지며, 관리책임자·비상전화는 직접 입력합니다.
   - 실측 크기(mm 단위)의 **SVG**(인쇄소 출력용 벡터)와 **PNG(150DPI)**로
     다운로드할 수 있습니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 사용법 1 — 웹 앱 (권장)

```bash
streamlit run app.py
```

브라우저가 열리면:

1. MSDS PDF 파일을 업로드합니다 (여러 개 가능).
2. 좌측에서 자동 추출된 제품명·신호어·그림문자·각 항목을 확인·수정합니다.
   **우측에는 엑셀 양식과 동일한 모양의 미리보기**가 표시되며, 수정하는 즉시 반영됩니다.
3. **엑셀 파일 생성 → 다운로드** 버튼으로 완성된 양식을 받습니다.

## 사용법 2 — 단일 HTML (설치 불필요)

`standalone/MSDS_관리요령_작성기.html` 파일 하나를 브라우저(크롬·엣지)에서 열기만 하면
됩니다. Python 설치가 필요 없고, 오프라인에서도 동작하며, PDF가 외부로 전송되지 않습니다.
기능은 웹 앱과 동일합니다(자동 추출 → 좌측 편집/우측 미리보기 → xlsx 다운로드,
한 파일당 최대 20개 물질).

수정 후 다시 빌드하려면:

```bash
cd standalone && python build_html.py
```

## 사용법 3 — 명령행

```bash
python cli.py msds1.pdf msds2.pdf -o 관리요령.xlsx
```

## 자동으로 채워지는 항목 (MSDS 참조 조항)

각 입력란 옆에도 아래 참조 조항이 표시됩니다.

| 양식 항목 | MSDS 참조 조항 |
|---|---|
| 제품명 | 1항 화학제품과 회사에 관한 정보 |
| GHS 그림문자, 신호어 | 2항 유해성·위험성 — 예방조치문구를 포함한 경고표지 항목 (명시가 없으면 H-code로 추론) |
| 건강·환경 유해성, 물리적 위험성 | 2항 유해성·위험성 — 유해·위험문구 |
| 안전·보건상의 취급주의 사항 | 2항 유해성·위험성 — 예방조치문구(예방·저장) |
| 적절한 보호구 | 8항 노출방지 및 개인보호구 (호흡기·눈·손·신체 보호) |
| 응급조치(흡입/피부·눈/먹었을 때) | 4항 응급조치 요령 |
| 응급대응(소화제·화재 유해성·누출 대처) | 5항 폭발·화재시 대처방법, 6항 누출사고 시 대처방법 |

## 파일 구성

```
app.py            # Streamlit 웹 앱
cli.py            # 명령행 도구
msds_parser.py    # MSDS PDF 파싱(항목 추출, 난독화 폰트 복원 포함)
ko_spacing.py     # 한글 띄어쓰기 자동 교정(MSDS 도메인 사전)
excel_writer.py   # 양식 시트 복제·기입, 그림문자 삽입
sign_writer.py    # 유해화학물질 규격표지(별표 2) SVG 생성
preview.py        # 엑셀 양식 모양의 HTML 미리보기 생성
ghs_data.py       # GHS 표준 H-code 문구·그림문자·신호어 데이터
assets/template.xlsx   # 원본과 동일한 빈 양식(시트 1장)
assets/ghs/GHS0*.png   # GHS 그림문자 이미지
standalone/MSDS_관리요령_작성기.html  # 설치 없이 쓰는 단일 HTML 버전(빌드 산출물)
standalone/src/app.html               # 단일 HTML 소스
standalone/build_html.py              # 단일 HTML 빌드 스크립트
standalone/vendor/                    # 내장 라이브러리(pdf.js, ExcelJS, JSZip, 한국어 CMap)
tests/            # 샘플 MSDS PDF 및 생성 스크립트
```

## 참고 사항

- **스캔본(이미지) PDF**는 텍스트를 추출할 수 없습니다. OCR 처리된 PDF를 사용하거나
  웹 앱에서 항목을 직접 입력해 주세요.
- 일부 MSDS 생성 프로그램(구버전 DR-Software 등)이 만든 PDF는 한글 폰트가
  난독화되어 일반 도구로는 텍스트가 추출되지 않습니다. 이 프로그램은 폰트의
  글리프 배치(Arial Unicode MS)를 역산해 한글을 복원합니다.
- 원문의 띄어쓰기가 깨진 문서("신 선 한 공 기", "즉시물로씻는다")는 MSDS
  도메인 사전 기반으로 띄어쓰기를 자동 교정합니다(`ko_spacing.py`).
  글자 자체는 바꾸지 않으며, 이상이 감지된 구간에만 적용됩니다.
- 고용노동부 고시 16개 항목 형식의 국문 MSDS에 최적화되어 있습니다. 형식이 다른
  문서도 키워드 기반으로 최대한 추출하며, 실패한 항목은 경고로 표시됩니다.
- GHS 그림문자 9종은 모두 UN GHS 표준 도안입니다. GHS05·07·08·09는 원본 양식에
  들어 있던 이미지 그대로이고, GHS01~04·06은 공식 표준 도안
  (`@ghs-hazard-pictograms/assets` 패키지, GHS-pictogram-* 시리즈)입니다.
- 유해·위험문구에는 H290, 예방조치문구에는 P260 같은 **코드는 기재하지 않고
  코드 뒤의 문구만** 기재합니다. 신호어가 없거나, 유해·위험문구/예방조치문구가
  없는 경우(원문에 "없음"·"내용없음"·"누락" 등으로 적힌 경우 포함)에는
  **"해당없음"**으로 기재합니다. 2항 유해성·위험성에 H-code가 하나도 없는
  물질도 유해·위험문구를 "해당없음"으로 기재합니다.
- 내용이 긴 항목은 **행 높이가 자동으로 늘어나** 글자가 가려지지 않습니다.
  인쇄 설정이 "A4 세로, 한 페이지 맞춤"으로 지정되므로 행이 늘어나도
  시트(탭)마다 항상 A4 한 장에 출력됩니다.
- 자동 추출 결과는 반드시 **MSDS 원본과 대조·확인** 후 사용하세요.
