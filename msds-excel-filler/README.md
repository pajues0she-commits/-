# 켐세이프 (ChemSafe) — 화학물질 통합 안전관리 도구

MSDS 기반의 관리요령 엑셀 · 도입검토 · 위험성평가 · 유해화학물질 규격표지,
네 가지 산출물을 자동으로 만들어 주는 프로그램입니다. 메인 화면의
**🏠 대시보드**에서는 회사 CI와 함께 등록된 화학물질의 **연간 도입검토
건수·정보등록 건수**와 도입검토 대상 중 **위험성평가 완료 건수**를 한눈에
확인할 수 있습니다(작성일 기준 연도별 집계, 담당자 검토 결과 '대상 아님'
체크 등록은 제외).

1. **화학물질 작업공정별 관리요령** — MSDS(물질안전보건자료) PDF를 업로드하면
   「화학물질 작업공정별 관리 요령」 엑셀 양식을 자동으로 채웁니다. 결과물은 원본
   양식과 동일한 서식(병합 셀·글꼴·테두리·GHS 그림문자 포함)의 `.xlsx` 파일로
   다운로드됩니다. PDF를 여러 개 올리면 물질별로 시트가 하나씩 생성됩니다.
   MSDS 업로드 창은 이 메뉴 안에 있습니다.
   - "적절한 보호구"(8항)는 전문을 그대로 옮기지 않고 **보호구 종류별(호흡기·눈·
     손·신체)로 핵심 문장 두 개 내외**만 요약해 기재합니다(성분별 노출농도 구간
     나열 등은 제외). 라벨에 콜론이 없는 형식("호흡기 보호 ○○○ 착용")도
     인식합니다.
2. **화학물질 도입검토** — MSDS를 등록하면 **화학물질명·제조사·주요성분 및
   함량**(3항)을 자동 인식해 비교표를 만들고, 기존 등록 이력과 비교해
   **도입검토 대상·정보등록 대상** 여부를 자동 판독합니다.
   - 작성일(연도~날짜)은 작성자가 직접 입력하며, **일괄 작업**(작성일
     일괄등록·모든 MSDS 일괄 등록·업로드 일괄 삭제)으로 여러 건을 한 번에
     처리할 수 있습니다.
   - 판독 기준(도입검토 대상·정보등록 대상 정의)은 프로그램 안의
     「기준 보기」에서 확인할 수 있습니다. 판독 로직: 성분 비교는 **CAS
     번호·함유량 기준**이라 성분명 표기 차이(물/Water)는 같은 물질로
     봅니다. 기존 등록과 **CAS 번호·함유량·제조사가 모두 동일하면 도입검토·
     정보등록 대상 아님** — 단, **MSDS 개정일자가 변경되었으면 정보등록
     대상**입니다. 조성이 같아도 **제조사가 변경되었으면 도입검토 대상**,
     같은 이름인데 조성이 다르면 "도입검토 대상(물질 변경)", 등록 이력이
     없으면 "도입검토 대상(신규 도입)". "일반 소매점에서 일반 소비자
     대상으로 판매되는 물질"은 체크로 정보등록에서 제외합니다. MSDS
     개정일자(최종 개정일자)는 자동 추출되며 수정할 수 있습니다.
   - 등록된 정보는 **누적 관리**됩니다(웹 앱은 `review_db.json` 파일, 단일
     HTML은 브라우저 localStorage). 같은 물질의 새 MSDS를 등록하면 이전 등록과
     성분·함유량을 나란히 비교하는 표가 표시되고, 물질명·제조사·CAS 번호
     검색과 **작성일 기준 기간별 조회**(시작일~종료일)를 지원하며, 표시된
     등록을 일괄 삭제할 수 있습니다. **엑셀로 내보내기** 버튼으로 등록
     목록과 업로드 비교표를 `.xlsx` 파일로 받을 수 있고, "도입검토 대상"
     셀은 노랑, "정보등록 대상" 셀은 초록으로 컬러마킹됩니다.
   - CAS 번호를 밝히지 않는 **"영업비밀" 성분**도 성분 표에 그대로
     들어갑니다(3항에서 자동 인식, 직접 입력도 가능).
   - **등록된 화학물질 조회** 목록에서 도입검토 대상 문구 아래의
     「🧪 위험성 평가」 버튼으로 인식 결과를 가지고 위험성평가 메뉴로 바로
     이동하며, 위험성평가 엑셀을 다운로드하면 목록에 **"위험성평가 완료"**
     (완료일)로 표시됩니다.
   - 도입검토·정보등록 대상으로 판정되었지만 담당자 검토 결과 대상이 아닌
     경우, 조회 목록의 **"도입검토 대상 아님" 체크박스**로 표시할 수
     있습니다(표시 문구가 "대상 아님(담당자 검토)"로 바뀌고 대시보드
     집계·위험성평가 대상에서 제외).
3. **화학물질 위험성평가** — 도입검토 대상 화학물질의 위험성평가
   (물리화학적 · 환경오염 · 작업자 안전보건, **유해성(강도)×가능성(빈도)**)를
   작성하고, 사내 「화학물질 위험성평가 Tool」 엑셀 양식
   (`assets/risk_template.xlsx`)으로 내려받습니다.
   - MSDS에서 **자동 인식**되는 항목: 제품명·제조사·개정일자·구성성분(1·3항),
     **H-Code(2항 — H314/H340/H350/H360은 구분(Cat)까지)**, 노출기준
     TWA(8항), 인화점·끓는점·자연발화온도·증기압(kPa/Pa는 mmHg로 자동
     환산)·logKow·분해온도(9항), LD50/LC50·IARC(11항), 어류 LC50·물벼룩
     EC50·BCF·생분해도·Koc(12항). 자동 인식되지 않는 항목(물 반응성·금기물질
     수·분해 생성물, 취급 빈도·취급량·공정 환경 등)은 작성자가 직접
     입력·선택합니다.
   - **직접 입력이 필요하거나 MSDS 판독이 안 된(빈) 항목은 빨간 칸**으로
     표시되며, 값을 입력하면 표시가 사라집니다.
   - 유해성 점수(분야별 8개 항목, 1~5점)의 **[참고값]은 양식과 동일한
     수식으로 자동 계산**되어 항목 옆에 표시되고, **점수 선택란은 기본
     (선택)** 입니다 — 작성자가 참고값을 확인하고 항목별 위험성을 직접
     선택하는 취지이며(참고값과 다르게 평가하면 비고에 사유 기재), 「[참고값]
     으로 일괄 채우기」 버튼으로 한 번에 채울 수도 있습니다. 가능성(**취급
     횟수·1회 취급량은 한 번만 입력하면 세 분야에 공통 반영**, 분야별 환경
     항목만 각각 선택)과 **저감대책(⑥ 저감대책DB, 위계별 최대 3개)**을
     선택하면 위험도·허용 여부·저감 후 최종 위험도·종합 판정이 실시간으로
     계산됩니다. 산정식은 양식의 엑셀 수식을 포팅한 것입니다
     (`risk_logic.py`).
   - 종합 판정 기준: 1-4점 저위험(도입 가능) / 5-9점 중위험(도입 가능,
     추가 저감대책 검토 권장) / **10-16점 고위험 — 부서장 검토 및
     안전보건관리책임자 승인 하에 도입 가능** / 17-25점 허용 불가(원칙적
     도입 불가). 치명항목(유해성 5점)은 참고 정보로만 표시합니다.
   - **엑셀 다운로드**는 양식 원본의 수식·서식·시트를 그대로 유지한 채 입력
     셀만 채우므로, 엑셀에서 열면 수식이 재계산되어 화면과 동일한 결과가
     표시됩니다.
4. **유해화학물질 규격표지** — 화학물질관리법 시행규칙 [별표 2]
   「유해화학물질의 표시방법」(제12조제2항 관련) 1호(보관·저장시설 또는 진열·보관
   장소 표지) 규격에 맞는 표지판 시안을 만듭니다.
   - 규격: **a=50cm**, b=(3/2)a=**75cm**, c=(1/4)a=**12.5cm**, d=(1/4)a=**12.5cm**
   - 색상: 바탕 흰색 / 테두리 검정 / "유해화학물질" 글자 빨강(테두리 높이의 65% 이상)
     / 관리책임자·비상전화 글자 검정
   - **화학물질명을 입력하면 CAS 번호·국제연합번호(UN No.)·GHS 그림문자가
     자동 입력됩니다.** 앱에 내장된 화학물질 정보(`chem_db.py`, 산업 현장에서 흔히
     취급하는 유해화학물질 약 80종 — 물질명·별칭(가성소다, IPA 등)·영문명·CAS 번호로
     검색)에서 찾으며, 인터넷 연결·인증키 없이 동작합니다. 검색 결과가 여러 건이면
     목록에서 선택하고, 없으면 물질명만 추가된 뒤 모든 항목(물질명·CAS 번호·
     국제연합번호·그림문자)을 직접 입력·수정할 수 있습니다.
   - 하단 표에는 물질명·국제연합번호·그림문자가 채워지며, 관리책임자·비상전화는
     직접 입력합니다. CAS 번호는 교차 확인(Cross check)용 조회 정보로 입력 화면에만
     표시되고 **표지판에는 표기되지 않습니다.**
   - 실측 크기(mm 단위)의 **SVG**(인쇄소 출력용 벡터)와 **PNG(150DPI)**로
     다운로드할 수 있습니다.
   - 내장 물질 정보는 참고용 요약이므로 표지 제작 전에 반드시 해당 제품의 MSDS와
     대조해 확인하세요(같은 물질이라도 농도·제형에 따라 분류가 달라질 수 있습니다).

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 사용법 1 — 웹 앱 (권장)

```bash
streamlit run app.py
```

브라우저가 열리면:

1. MSDS PDF 파일을 업로드합니다 (여러 개 가능).
2. 좌측에서 자동 추출된 제품명·신호어·그림문자·각 항목을 확인·수정합니다.
   **우측에는 엑셀 양식과 동일한 모양의 미리보기**가 표시되며, 수정하는 즉시 반영됩니다.
3. **엑셀 파일 생성 → 다운로드** 버튼으로 완성된 양식을 받습니다.

## 사용법 2 — 단일 HTML (설치 불필요)

`standalone/켐세이프_화학물질통합안전관리.html` 파일 하나를 브라우저(크롬·엣지)에서 열기만 하면
됩니다. Python 설치가 필요 없고, 오프라인에서도 동작하며, PDF가 외부로 전송되지 않습니다.
기능은 웹 앱과 동일합니다(자동 추출 → 좌측 편집/우측 미리보기 → xlsx 다운로드,
한 파일당 최대 20개 물질).

수정 후 다시 빌드하려면:

```bash
cd standalone && python build_html.py
```

## 사용법 3 — 명령행

```bash
python cli.py msds1.pdf msds2.pdf -o 관리요령.xlsx
```

## 자동으로 채워지는 항목 (MSDS 참조 조항)

각 입력란 옆에도 아래 참조 조항이 표시됩니다.

| 양식 항목 | MSDS 참조 조항 |
|---|---|
| 제품명 | 1항 화학제품과 회사에 관한 정보 |
| GHS 그림문자, 신호어 | 2항 유해성·위험성 — 예방조치문구를 포함한 경고표지 항목 (명시가 없으면 H-code로 추론) |
| 건강·환경 유해성, 물리적 위험성 | 2항 유해성·위험성 — 유해·위험문구 |
| 안전·보건상의 취급주의 사항 | 2항 유해성·위험성 — 예방조치문구(예방·저장) |
| 적절한 보호구 | 8항 노출방지 및 개인보호구 (호흡기·눈·손·신체 보호, 종류별 핵심 문장 2개 내외로 요약) |
| 응급조치(흡입/피부·눈/먹었을 때) | 4항 응급조치 요령 |
| 응급대응(소화제·화재 유해성·누출 대처) | 5항 폭발·화재시 대처방법, 6항 누출사고 시 대처방법 |

## 파일 구성

```
app.py            # Streamlit 웹 앱
cli.py            # 명령행 도구
msds_parser.py    # MSDS PDF 파싱(항목 추출, 난독화 폰트 복원 포함)
ko_spacing.py     # 한글 띄어쓰기 자동 교정(MSDS 도메인 사전)
excel_writer.py   # 양식 시트 복제·기입, 그림문자 삽입
sign_writer.py    # 유해화학물질 규격표지(별표 2) SVG 생성
chem_db.py        # 규격표지용 내장 화학물질 정보(CAS·UN번호·그림문자)
review_logic.py   # 화학물질 도입검토 — 대상 판독 로직·기준 문안
risk_logic.py     # 화학물질 위험성평가 — 점수 산정 로직·기준 데이터·양식 기입
assets/risk_template.xlsx  # 화학물질 위험성평가 Tool 엑셀 양식 원본
preview.py        # 엑셀 양식 모양의 HTML 미리보기 생성
ghs_data.py       # GHS 표준 H-code 문구·그림문자·신호어 데이터
assets/template.xlsx   # 원본과 동일한 빈 양식(시트 1장)
assets/ghs/GHS0*.png   # GHS 그림문자 이미지
standalone/켐세이프_화학물질통합안전관리.html  # 설치 없이 쓰는 단일 HTML 버전(빌드 산출물)
standalone/src/app.html               # 단일 HTML 소스
standalone/build_html.py              # 단일 HTML 빌드 스크립트
standalone/vendor/                    # 내장 라이브러리(pdf.js, ExcelJS, JSZip, 한국어 CMap)
tests/            # 샘플 MSDS PDF 및 생성 스크립트
```

## 참고 사항

- **스캔본(이미지) PDF**는 텍스트를 추출할 수 없습니다. OCR 처리된 PDF를 사용하거나
  웹 앱에서 항목을 직접 입력해 주세요.
- 일부 MSDS 생성 프로그램(구버전 DR-Software 등)이 만든 PDF는 한글 폰트가
  난독화되어 일반 도구로는 텍스트가 추출되지 않습니다. 이 프로그램은 폰트의
  글리프 배치(Arial Unicode MS)를 역산해 한글을 복원합니다.
- 원문의 띄어쓰기가 깨진 문서("신 선 한 공 기", "즉시물로씻는다")는 MSDS
  도메인 사전 기반으로 띄어쓰기를 자동 교정합니다(`ko_spacing.py`).
  글자 자체는 바꾸지 않으며, 이상이 감지된 구간에만 적용됩니다.
- 고용노동부 고시 16개 항목 형식의 국문 MSDS에 최적화되어 있습니다. 형식이 다른
  문서도 키워드 기반으로 최대한 추출하며, 실패한 항목은 경고로 표시됩니다.
- GHS 그림문자 9종은 모두 UN GHS 표준 도안입니다. GHS05·07·08·09는 원본 양식에
  들어 있던 이미지 그대로이고, GHS01~04·06은 공식 표준 도안
  (`@ghs-hazard-pictograms/assets` 패키지, GHS-pictogram-* 시리즈)입니다.
- 유해·위험문구에는 H290, 예방조치문구에는 P260 같은 **코드는 기재하지 않고
  코드 뒤의 문구만** 기재합니다. 신호어가 없거나, 유해·위험문구/예방조치문구가
  없는 경우(원문에 "없음"·"내용없음"·"누락" 등으로 적힌 경우 포함)에는
  **"해당없음"**으로 기재합니다. 2항 유해성·위험성에 H-code가 하나도 없는
  물질도 유해·위험문구를 "해당없음"으로 기재합니다.
- 내용이 긴 항목은 **행 높이가 자동으로 늘어나** 글자가 가려지지 않습니다.
  인쇄 설정이 "A4 세로, 한 페이지 맞춤"으로 지정되므로 행이 늘어나도
  시트(탭)마다 항상 A4 한 장에 출력됩니다.
