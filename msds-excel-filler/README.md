# MSDS PDF → 화학물질 작업공정별 관리 요령 자동 작성

MSDS(물질안전보건자료) PDF를 업로드하면 **「화학물질 작업공정별 관리 요령」 엑셀 양식**을
자동으로 채워 주는 프로그램입니다. 결과물은 원본 양식과 동일한 서식(병합 셀·글꼴·테두리·
GHS 그림문자 포함)의 `.xlsx` 파일로 다운로드됩니다. PDF를 여러 개 올리면 물질별로
시트가 하나씩 생성됩니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

## 사용법 1 — 웹 앱 (권장)

```bash
streamlit run app.py
```

브라우저가 열리면:

1. MSDS PDF 파일을 업로드합니다 (여러 개 가능).
2. 좌측에서 자동 추출된 제품명·신호어·그림문자·각 항목을 확인·수정합니다.
   **우측에는 엑셀 양식과 동일한 모양의 미리보기**가 표시되며, 수정하는 즉시 반영됩니다.
3. **엑셀 파일 생성 → 다운로드** 버튼으로 완성된 양식을 받습니다.

## 사용법 2 — 명령행

```bash
python cli.py msds1.pdf msds2.pdf -o 관리요령.xlsx
```

## 자동으로 채워지는 항목

| 양식 항목 | MSDS 출처 |
|---|---|
| 제품명 | 1항 (제품명) |
| GHS 그림문자, 신호어 | 2항 (명시된 값, 없으면 H-code로 추론) |
| 건강·환경 유해성, 물리적 위험성 | 2항 유해·위험문구 |
| 안전·보건상의 취급주의 사항 | 2항 예방조치문구(예방·저장) |
| 적절한 보호구 | 8항 (호흡기·눈·손·신체 보호) |
| 응급조치(흡입/피부·눈/먹었을 때) | 4항 |
| 응급대응(소화제·화재 유해성·누출 대처) | 5항·6항 |

## 파일 구성

```
app.py            # Streamlit 웹 앱
cli.py            # 명령행 도구
msds_parser.py    # MSDS PDF 파싱(항목 추출)
excel_writer.py   # 양식 시트 복제·기입, 그림문자 삽입
preview.py        # 엑셀 양식 모양의 HTML 미리보기 생성
ghs_data.py       # GHS 표준 H-code 문구·그림문자·신호어 데이터
assets/template.xlsx   # 원본과 동일한 빈 양식(시트 1장)
assets/ghs/GHS0*.png   # GHS 그림문자 이미지
tests/            # 샘플 MSDS PDF 및 생성 스크립트
```

## 참고 사항

- **스캔본(이미지) PDF**는 텍스트를 추출할 수 없습니다. OCR 처리된 PDF를 사용하거나
  웹 앱에서 항목을 직접 입력해 주세요.
- 고용노동부 고시 16개 항목 형식의 국문 MSDS에 최적화되어 있습니다. 형식이 다른
  문서도 키워드 기반으로 최대한 추출하며, 실패한 항목은 경고로 표시됩니다.
- 그림문자 중 GHS05·07·08·09는 원본 양식에 들어 있던 공식 이미지이고,
  GHS01~04·06은 표준 도안을 본떠 제작한 이미지입니다. 필요하면
  `assets/ghs/`의 PNG를 공식 이미지로 교체하면 됩니다.
- 자동 추출 결과는 반드시 **MSDS 원본과 대조·확인** 후 사용하세요.
