# 수소(H₂) 고압가스 실린더 안전 — 위험성평가 영상

미고정 실린더의 전도·수소폭발 위험과 고정 조치를 보여주는 **20초 모션그래픽** 안전 영상입니다.
YouTube 업로드용(1920×1080 / 30fps). 배경으로 현장 사진을 그대로 사용합니다.

## 구성 (20초)

| 구간 | 시간 | 내용 |
|------|------|------|
| 타이틀 | 0.0–3.2s | "넘어지면, 로켓이 됩니다" / 고압가스 수소(H₂) 실린더 고정 안전 |
| 전환 | 3.2–3.8s | 붉은 대각 와이프 |
| 위험상황 ① | 3.8–9.8s | 미고정 실린더 전도 → **수소 폭발!** (화구·충격파·스파크·화면 흔들림) |
| 전환 | 9.8–10.4s | 흰 플래시 + 청록 와이프 |
| 안전조치 | 10.4–16.6s | 작업자가 체인·스트랩으로 고정, 체크 표시 "넘어짐 방지 완료" |
| 안전 메시지 | 16.6–20.0s | 자막: "고압가스 실린더, 넘어지면 로켓이 됩니다. 안전한 취급을 위해 보관할 때는 반드시 고정 조치를 해주세요." + 엔드카드 |

> 대사는 **화면 자막**으로 표시됩니다(무음). 이 환경엔 오디오 인코더가 없어 나레이션 음성은 포함하지 않습니다.

## 배경 사진 교체

현장 사진을 `assets/photo.jpg` 로 저장하면 자동으로 배경(cover)으로 사용됩니다.
파일이 없으면 유사한 합성 배경으로 대체 렌더링됩니다.

```bash
cp /경로/현장사진.jpg assets/photo.jpg
```

## 빌드

```bash
./build.sh
# → hydrogen_cylinder_safety.webm 생성
```

- `render.mjs` : Playwright(Chromium)로 `index.html` 을 프레임 단위(30fps×20s=600장) 결정론적 캡처 → `frames/*.jpg`
- `build.sh`   : 캡처 후 번들 ffmpeg 로 VP8 webm 인코딩 (오디오 없음)

## 파일

- `index.html` — Canvas 2D 애니메이션 (모든 장면·전환·효과). `window.renderAt(t)` 로 임의 시점 렌더.
- `render.mjs` — 프레임 캡처 스크립트
- `build.sh`   — 캡처 + 인코딩 파이프라인
- `assets/`    — 배경 사진(`photo.jpg`) 위치

## 편집 팁

- 타임라인은 `index.html` 상단 `const T = {…}` 에서 초 단위로 조정.
- 문구·색상은 각 `sceneXXX()` 함수에서 수정.
- MP4가 필요하면 별도 환경의 ffmpeg(H.264)로 `ffmpeg -i hydrogen_cylinder_safety.webm -c:v libx264 -crf 18 out.mp4` 변환.
